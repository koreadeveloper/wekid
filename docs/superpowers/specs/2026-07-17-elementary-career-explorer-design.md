# 초등학생 직업 탐험 개편 설계

## 목표

초등학생이 친숙하게 느끼는 107개 직업을 바탕으로, 한 직업을 단정하지 않고 여러 적합 분야와 직업을 탐색하게 하는 진로 설문을 만든다. 결과에서는 추천과 아이가 고른 꿈을 함께 보존하고, 관리자는 모든 응답과 선택 과정을 조회할 수 있어야 한다.

## 결과 분야

결과는 다음 8개 분야로 표현한다. 직업 지도용 14개 세부 분야는 각 결과 분야에 연결되지만, 결과 화면에서는 8개 분야만 사용한다.

1. 🔬 호기심 많은 탐구자 — 과학·연구
2. 💻 영리한 미래 설계자 — 기술·디지털
3. 🎨 상상력 넘치는 창작자 — 예술·콘텐츠
4. 🤝 따뜻한 성장 조력자 — 사람·교육
5. 🩺 다정한 생명 수호자 — 의료·돌봄
6. 🚀 도전하는 아이디어 리더 — 비즈니스·리더십
7. 🛡️ 정의로운 세상 수호자 — 사회·안전·공공
8. ⚡ 활력 넘치는 행동가 — 자연·현장·스포츠

## 문항 승인 게이트

문항과 선택지는 계산 엔진보다 먼저 확정한다.

1. 구현 전에 24개 문항의 전체 문구, 선택지, 각 선택지가 표현하는 활동을 사용자에게 제시한다.
2. 사용자가 문항 초안을 명시적으로 승인하기 전에는 점수 계산식, 결과 추천 로직, 실제 문항 데이터 파일을 만들거나 수정하지 않는다.
3. 승인된 문항만 점수 태그와 추천 데이터의 근거로 사용한다.

문항 구성 목표는 활동 흥미 16문항과 일하는 방식 8문항이다. 모든 문항은 초등학생의 학교·놀이·친구·만들기·미디어 생활에서 출발하고, 특정 직업을 정답처럼 유도하지 않는다.

## 승인 후 추천 구조

문항 승인 뒤에 다음 원칙으로 계산 구조를 구현한다.

- 활동 문항은 8개 결과 분야가 동등한 측정 기회를 갖도록 배치한다.
- 선택지마다 분야와 활동 태그를 명시한다.
- 분야 점수는 해당 분야를 실제로 측정한 선택지 수를 기준으로 정규화한다.
- 직업 점수는 분야 적합도, 활동 태그, 일하는 방식 태그를 합산하되, 각 직업의 가능한 최대 점수를 실제 문항 조합으로 검증한다.
- 이름순 정렬로 동점을 깨지 않는다. 같은 점수권 직업은 함께 표시한다.
- 결과는 상위 3개 분야와 분야별 3개 이상의 직업을 추천한다. 대표 직업 1개를 강제하지 않는다.
- 무작위 응답 분포 시뮬레이션과 의도된 응답 시나리오 테스트로 특정 직업의 과다 노출, 추천 불가 직업, 중복 프로필을 검사한다.

## 결과 경험

결과 화면은 다음 순서를 따른다.

1. 상위 3개 적합 분야와 쉬운 설명을 표시한다.
2. 각 분야에서 추천 직업을 여러 개 제시하고 상세 설명을 연다.
3. 전체 107개 직업을 검색·분야별 탐색할 수 있게 한다.
4. 아이가 추천 직업 또는 전체 목록에서 `내가 고른 꿈`을 선택할 수 있게 한다.
5. 목록에 없는 꿈은 직접 입력할 수 있다.
6. 선택 없이도 `아직 더 찾아볼래요` 상태로 결과를 저장할 수 있다.
7. PDF와 이미지 결과에는 추천 분야, 추천 직업, 아이가 고른 꿈을 함께 표시한다.

## 저장과 관리자 조회

새 결과는 `questionnaireVersion: 2`로 저장하고, 다음 정보를 포함한다.

- 문항과 선택지의 스냅샷
- 문항별 선택값과 사람이 읽을 수 있는 선택 문구
- 분야별 점수와 추천 근거 태그
- 추천 분야와 추천 직업 목록
- 아이가 고른 꿈, 선택 유형(목록 선택·직접 입력·미선택)

관리자 화면은 새 결과의 모든 응답, 분야 점수, 추천 목록, 최종 꿈을 상세 화면·CSV·인쇄 보고서에서 표시한다. 기존 결과는 `questionnaireVersion: 1`로 구분해 기존 문항 사전을 사용하고, 새 문항으로 재해석하지 않는다.

## 검증 기준

- 107개 직업은 중복 없이 세부 분야와 상세 설명을 모두 가진다.
- 모든 활동 문항은 결과 분야의 측정 기회를 균등하게 제공한다.
- 모든 직업은 의도된 응답 시나리오에서 하나 이상의 추천 목록에 등장할 수 있다.
- 동일한 직업 프로필이 있으면 병합하거나 구분 태그를 추가한다.
- 결과 선택·직접 입력·미선택 저장과 관리자 조회가 모두 작동한다.
- 기존 Firestore 기록과 새 기록이 같은 관리자 화면에서 올바른 문항 버전으로 표시된다.
