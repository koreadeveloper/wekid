# WEKID 초등 진로 탐험 설문 안내서

기관 담당자용 배포·운영 안내서입니다. 아이가 결과를 편안하게 탐색하고, 기관은 응답을 안전하게 확인할 수 있도록 사용해 주세요.

## 1. 설문 소개

WEKID 초등 진로 탐험은 초등학생이 두 활동 중 조금 더 해 보고 싶은 쪽을 고르면, 관심이 나타난 분야와 여러 직업을 함께 보여 주는 탐색형 설문입니다. 정답도, 한 가지로 확정되는 진로도 없습니다.

- 문항: 초등학생 눈높이의 A/B 문항 24개와 `아직 잘 모르겠어요`
- 결과: 8개 분야 중 최대 3개 방향과 분야별 여러 직업
- 직업 목록: 아이돌, 유튜버, 모델, CEO 등을 포함한 107개 직업
- 마지막 단계: 추천 직업·전체 목록·직접 입력·`아직 더 찾아볼래요` 중에서 아이가 자신의 꿈을 선택
- 소요 시간: 약 5~8분

결과는 아이의 가능성을 좁히거나 진로를 결정하는 자료가 아닙니다. 아이와 대화를 시작하기 위한 탐색 자료로만 활용해 주세요.

## 2. 배포 전 최종 점검

| --- | --- |

### 기관 배포 전에 반드시 할 일

현재 작업 환경에는 실제 Firebase 환경변수가 연결되어 있지 않습니다. 이 상태에서는 아이가 설문을 해도 결과가 관리자 페이지에 저장되지 않습니다. 아래 네 가지를 완료한 뒤 기관에 배포하세요.

1. Firebase 프로젝트를 만들고 Firestore Database와 Authentication을 준비합니다.
2. `.env.example`의 여섯 Firebase 값을 실제 배포 환경 변수로 등록합니다.
3. 이 프로젝트의 `firestore.rules`를 Firestore 규칙에 배포합니다.
4. 관리자 계정으로 로그인할 사용자의 Firebase UID에 맞춰 Firestore `admins/{UID}` 문서를 만들고, `role` 값을 반드시 `owner`로 설정합니다.

관리자 문서 예시는 아래와 같습니다.

```json
{
  "email": "admin@example.org",
  "role": "owner",
  "createdAt": "Firestore Timestamp"
}
```

또한 Firebase Authentication에서 관리자 로그인에 사용할 이메일/비밀번호 방식을 활성화해야 합니다. 기관 외 일반 응답자는 로그인하지 않아도 설문을 제출할 수 있지만, 결과 조회는 `owner` 권한의 관리자만 가능합니다.

## 3. 기관별 설문 링크 만들기

기관명을 URL에 넣으면 시작 화면의 센터명이 자동으로 입력되어 관리자 화면에서 기관별로 필터링할 수 있습니다.

```text
https://{배포도메인}/?centerName={기관명}
```

예를 들어 기관명이 `강남청소년센터`라면 다음 형식으로 배포합니다.

```text
https://{배포도메인}/?centerName=강남청소년센터
```

기관명은 가능하면 한 가지 표기로 통일해 주세요. 아이가 수정할 수 있으므로, 결과 조회 시에는 유사한 센터명도 함께 확인해 주세요.

## 4. 보호자·학생 전달용 안내문

아래 문구에서 링크만 기관별 설문 링크로 바꿔 사용하세요.

> 안녕하세요. 우리 기관에서는 아이들이 좋아하는 활동과 관심 있는 직업을 편안하게 탐색해 보는 **WEKID 초등 진로 탐험**을 진행합니다.
>
> 설문은 약 5~8분 정도 걸리며, 정답은 없습니다. 두 선택지 중 조금이라도 더 해 보고 싶은 쪽을 고르면 돼요. 결과는 한 가지 직업을 정해 주는 것이 아니라, 아이가 더 탐험해 볼 분야와 여러 직업을 알려 줍니다.
>
> 이름과 이메일은 선택 사항입니다. 원하지 않으면 이름 없이 시작할 수 있습니다.
>
> 설문 참여: {기관별 설문 링크}

## 5. 진행 방법

1. 아이가 기관별 설문 링크를 엽니다.
2. 이름은 선택으로 입력하고, 센터명이 맞는지 확인합니다.
3. 24개 문항에서 조금 더 해 보고 싶은 A 또는 B를 고릅니다. 고르기 어렵다면 `아직 잘 모르겠어요`를 선택합니다.
4. 결과에서 여러 분야와 직업을 함께 살펴봅니다.
5. 추천 직업, 전체 목록, 직접 입력, 또는 `아직 더 찾아볼래요` 중 하나를 선택해 결과를 저장합니다.
6. 필요하면 결과 이미지를 저장하거나 PDF 결과지를 내려받습니다.

`아직 잘 모르겠어요`를 많이 선택한 경우에는 특정 직업을 억지로 추천하지 않습니다. 아이가 전체 직업 목록에서 마음에 드는 꿈을 직접 고를 수 있게 도와 주세요.

## 6. 결과를 함께 볼 때의 대화 예시

- “이 직업 중에서 왜 이게 제일 눈에 들어왔어?”
- “결과에 나온 활동을 학교나 집에서 해 본 적이 있어?”
- “이번에는 잘 모르겠다고 했지만, 나중에 해 보고 싶은 건 뭐야?”
- “다음 달에 이 분야를 조금 더 알아볼 수 있는 활동은 무엇일까?”

피해야 할 표현: “이 결과가 나왔으니 너는 꼭 이 직업을 해야 해.”

## 7. 관리자 결과 확인 방법

1. 사이트 상단에서 `관리자` 화면으로 이동합니다.
2. Firebase Authentication에 등록된 기관 관리자 이메일과 비밀번호로 로그인합니다.
3. 센터·기간·이름·직업으로 결과를 필터링합니다.
4. 각 응답의 `상세 보기`에서 다음을 확인합니다.
   - 24개 문항별 선택
   - 8개 분야 점수와 선택 근거
   - 추천 분야·직업
   - 아이가 최종 선택한 꿈과 선택 방식
5. 필요한 경우 CSV 또는 관리자 보고서를 내려받습니다.

새 설문은 아이가 마지막에 꿈을 확인한 뒤 저장됩니다. 저장 전 페이지를 닫은 응답은 관리자 목록에 나타나지 않습니다.

## 8. 개인정보·운영 유의사항

- 이름과 이메일은 선택 사항이므로, 기관 운영에 꼭 필요하지 않다면 입력하지 않도록 안내하세요.
- CSV와 관리자 보고서에는 개인정보가 포함될 수 있습니다. 외부 공유, 공용 기기 저장, 무단 전송을 피하세요.
- 결과는 진로 상담의 보조 자료입니다. 중요한 진로·교육 판단에는 아이의 경험, 보호자·교사의 관찰, 전문 상담을 함께 고려하세요.
- 관리자 비밀번호와 Firebase 프로젝트 권한은 기관 담당자만 보관하세요.

## 9. 배포 당일 체크리스트

- [ ] 실제 배포 주소에서 설문을 1회 끝까지 진행했다.
- [ ] 마지막 꿈 선택 후 관리자 목록에 응답이 보인다.
- [ ] 기관별 URL의 센터명이 자동 입력된다.
- [ ] 관리자 계정 외에는 결과를 볼 수 없다.
- [ ] CSV에 문항별 응답, 8개 분야 점수, 최종 꿈이 포함된다.
- [ ] 기관명 표기와 보호자 안내문을 확정했다.
- [ ] 개인정보 취급 담당자와 보관 기간을 정했다.

## 10. 문제 해결

| 상황 | 확인할 내용 |
| --- | --- |
| 결과가 관리자에 보이지 않음 | Firebase 환경변수, Firestore 규칙 배포, 마지막 꿈 저장 완료 여부를 확인합니다. |
| 관리자 로그인 후 권한 없음 | Firebase UID와 `admins/{UID}` 문서, `role: owner` 값을 확인합니다. |
| 센터별 결과가 섞여 보임 | 배포 링크의 `centerName`과 아이가 입력한 센터명 표기를 통일합니다. |
| 결과가 한 가지로 단정되지 않음 | 정상입니다. 이 설문은 여러 탐색 방향과 직업을 함께 보여 줍니다. |
