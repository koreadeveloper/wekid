# 청소년 친화 직업 목록 및 설문 화면 개선 설계

## 목적

초등학생과 청소년이 이해하고 실제로 꿈꿔 볼 수 있는 직업 중심으로 기존 178개 직업 목록을 약 115개로 재구성한다. 설문 진입과 진행 화면의 문구를 더 자연스럽게 다듬고, 선택지 버튼의 가운데 회색 원을 제거한다.

## 범위

- 상단 브랜드 설명을 `청소년 진로 직업 테스트`로 변경한다.
- 설문 안내를 `마음에 더 가까운 선택지를 골라보세요. 마지막에 나에게 잘 어울리는 직업과 그 이유를 알려드려요.`로 변경한다.
- 직업 목록을 110~120개(목표 115개)로 축소한다.
- 사용자가 제시한 친숙한 직업을 포함한다. 예: 크리에이터(유튜버), 가수(아이돌), 모델, 프로게이머, 우주비행사, 치과의사, 승무원, 헤어 디자이너.
- 연구원·기획자·관리자처럼 비슷하고 지나치게 세분화된 항목은 대표 직업 하나로 통합하거나 제거한다.
- 선택지 버튼의 회색 원 장식을 제거하되, 선택·호버·키보드 포커스 상태는 유지한다.
- 제공된 위키드 로고를 파비콘으로 사용해 브라우저 탭 아이콘을 통일한다.

## 데이터 설계

`careerCategories`, `careerFits`, `detailedCareerDetails`는 동일한 직업명을 공유한다. 직업을 제거하거나 이름을 바꿀 때 세 데이터 집합을 함께 갱신한다.

- 카테고리는 아이들이 이해하기 쉬운 분야명과 대표 직업을 사용한다.
- 모든 표시 직업에는 추천 점수 데이터와 상세 정보가 존재해야 한다.
- 더 이상 표시하지 않는 직업은 추천 후보와 상세 정보에서도 제거한다.
- 중복 이름은 허용하지 않는다.
- 상세 정보가 없는 직업을 자동 생성하는 기존 보완 로직은 유지하되, 이번 목록의 직업은 모두 명시적 상세 정보를 갖는 것을 목표로 한다.

## 화면 설계

- TopBar의 보조 문구만 교체하며, 브랜드명과 기존 내비게이션 구조는 유지한다.
- QuizIntro의 제목은 이름이 있을 때 `OOO의 미래 직업 찾기`를 유지한다. 바로 아래 안내 문구만 새 문구로 교체한다.
- 선택지 버튼은 초록색의 둥근 사각형과 테두리·그림자만 보이게 한다. 회색 중앙 원을 만드는 요소 또는 의사 요소를 삭제한다.
- 로고 원본은 `public/brand/wekid-logo.png`에 두고, `index.html`의 아이콘 참조를 이 파일로 교체한다.

## 검증

- 직업 수가 110~120개 범위인지 확인한다.
- 필수 예시 직업이 모두 포함됐는지 확인한다.
- 카테고리·추천·상세 데이터 사이의 누락, 중복, 고아 참조가 없는지 검사한다.
- 문구와 선택지 버튼을 컴포넌트/스타일 수준에서 확인한다.
- HTML의 파비콘 참조와 빌드 결과의 로고 자산 포함 여부를 확인한다.
- 프로덕션 빌드를 실행한다.

## 제외 범위

- 관리자 로그인 후 명함 제작 탭을 노출하는 권한 변경은 별도 결정이 필요한 작업으로, 이 변경에는 포함하지 않는다.
- 설문 문항 및 추천 알고리즘 자체의 성격·점수 모델은 변경하지 않는다.
