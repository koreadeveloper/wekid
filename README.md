# 위키드 직업 탐험

초등학생이 24개 생활·놀이 상황 문항을 통해 여러 진로 방향을 탐험하는 React/Vite 웹앱입니다. 결과는 한 직업으로 단정하지 않고, 세 가지 분야와 여러 직업을 함께 보여 줍니다.

## 현재 진로 탐험 구성

| 항목 | 내용 |
| --- | --- |
| 직업 목록 | 초등학생 친화적인 107개 직업, 14개 직업 지도 분야 |
| 문항 | 승인된 활동 흥미 16개 + 일하는 방식 8개 |
| 결과 분야 | 과학·연구, 기술·디지털, 예술·콘텐츠, 사람·교육, 의료·돌봄, 비즈니스·리더십, 사회·안전·공공, 자연·현장·스포츠 |
| 추천 방식 | 상위 3개 분야와 분야별 여러 직업; 동점을 이름순으로 깨지 않음 |
| 최종 선택 | 추천 직업, 전체 목록, 직접 입력, `아직 더 찾아볼래요` 중 선택 |
| 관리자 | 설문 버전, 문항별 응답, 추천 분야·직업, 최종 꿈을 상세·CSV에서 확인 |

## 추천 계산 원칙

- `아직 잘 모르겠어요`는 점수의 분자와 분모에서 모두 제외합니다.
- 각 분야와 직업 적합도는 실제 A/B 선택지 중 가능한 최대값으로 나누어 정규화합니다.
- 직업 점수는 주 분야 적합도 65%, 활동 태그 적합도 20%, 일하는 방식 적합도 15%를 사용합니다.
- 결과는 탐험의 출발점이며, 아이의 진로를 확정하지 않습니다.

## 결과 분야 이름

1. 호기심 많은 탐구자 — 과학·연구
2. 영리한 미래 설계자 — 기술·디지털
3. 상상력 넘치는 창작자 — 예술·콘텐츠
4. 따뜻한 성장 조력자 — 사람·교육
5. 다정한 생명 수호자 — 의료·돌봄
6. 도전하는 아이디어 리더 — 비즈니스·리더십
7. 정의로운 세상 수호자 — 사회·안전·공공
8. 활력 넘치는 행동가 — 자연·현장·스포츠

## 실행

```bash
npm install
npm run dev
```

기본 주소는 `http://localhost:5173`입니다.

## 검증

```bash
npm test
npm run check:data
npm run check:distribution
npm run check:business-card
npm run build
```

`check:data`는 107개 직업, 8개 결과 분야, 24개 승인 문항, 중복 없는 직업 프로필과 상세 정보를 확인합니다. `check:distribution`은 10만 개의 결정론적 A/B 응답을 시뮬레이션하고, 모든 직업의 개별 도달 시나리오도 검사합니다.

## 주요 데이터와 화면

| 위치 | 역할 |
| --- | --- |
| `src/data/careerCatalog.ts` | 107개 직업의 표시명, 분야, 태그, 상세 설명 |
| `src/data/questionsV2.ts` | 승인된 24개 초등학생용 문항 |
| `src/lib/careerScoring.ts` | 정규화된 다분야·다직업 추천 계산 |
| `src/pages/result/` | 분야별 결과, 직업 상세, 꿈 선택, 이미지/PDF 저장 |
| `src/pages/admin/` | v1/v2 응답을 함께 조회하는 관리자 화면 |
| `src/data/legacyQuestionsV1.ts` | 기존 Firestore 결과를 위한 고정 문항 사전 |

## Firestore 결과 버전

- v1: 기존 30문항/대표 직업 결과를 기존 문항으로 읽습니다.
- v2: 답변 스냅샷, 8개 분야 점수, 추천 3개 분야, 최종 꿈 선택을 저장합니다.

새 결과는 아이가 최종 꿈을 확인했을 때만 저장됩니다. 관리자만 읽을 수 있고, 클라이언트에서 수정·삭제할 수 없습니다.
